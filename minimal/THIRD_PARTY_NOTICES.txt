Third-Party Notices
===================

This application includes third-party software, an API, and assets.
Notices for each are listed below.

This document applies to both the Glances Client advanced application
and the Glances Client minimal application, which share the same icon
and are built on the same API.

--------------------------------------------------------------------------------

Glances (REST API & project)
----------------------------

Both the minimal and advanced applications are built on the Glances
REST API, which powers every metric shown (CPU, memory, disks, network,
Docker containers, services, and more). Without the Glances project,
this application would not be possible.

  Project:    Glances — An eye on your system
  Developer:  Nicolas Hennion (nicolargo)

Original Glances authors and contributors are listed in the Glances
project repository. All source code, system metrics, and API
implementations originate from the Glances project.
