# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities. Report them
privately via GitHub's [private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository (Security → Report a vulnerability).

## What to include

- App version and Android version
- Steps to reproduce
- Impact description
- If possible, a minimal proof of concept

## Scope

- The Android app (`lib/`, `android/`)
- Release signing configuration

Out of scope: the Glances server itself — report issues to the
[Glances project](https://github.com/nicolargo/glances).

## Response

You can expect an acknowledgment within 5 business days, and a fix/status
update as soon as the issue is triaged.
